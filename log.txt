LumenOS 开发日志
================

项目名称：LumenOS
项目类型：个人 Web 操作系统
技术栈：HTML、CSS、JavaScript

开发节点总览
------------

首先，完成了 LumenOS 的基础桌面、启动流程、视觉风格和通用窗口系统。

其次，围绕个人内容完成了 Field Notes、About.me、The Atlas 和 System 等核心应用，并补充了数据保存、背景设置、窗口拖拽和响应式布局。

最后，增加了 Mini Runner 小游戏和 Virtual Files 文件管理器，使桌面具备更多可操作内容，并支持在浏览器中创建和保存虚拟文件。

一、项目起点
------------

本项目参考 Hack Club 的 WebOS 教程完成。目标不是制作一个普通的个人主页，而是把个人介绍、兴趣、想法和作品组织成一个可以探索的桌面操作系统。

项目从一个空的 GitHub 工作区开始，没有使用前端框架或第三方运行时依赖，采用原生 HTML、CSS 和 JavaScript 完成，以便清楚地理解每个交互的实现方式。

二、视觉设计
------------

LumenOS 使用米白、深墨绿、珊瑚色和酸绿色作为主要颜色，整体风格希望同时具有编辑感、个人感和实验性。

桌面背景使用柔和的绿色渐变和网格纹理，顶部栏采用半透明背景和模糊效果，应用窗口使用类似桌面操作系统的标题栏、关闭按钮和最小化按钮。

三、核心功能开发
----------------

1. 启动界面

首先制作了启动欢迎屏幕，用户点击 Enter LumenOS 后进入桌面。启动屏幕包含项目名称、欢迎文案、系统状态和进入按钮。

2. 桌面和顶部栏

桌面包含应用图标、顶部栏、实时日期时间和底部 Dock。顶部栏中的时钟由 JavaScript 定时更新，每秒显示当前时间。

3. 可交互窗口

每个应用都使用独立窗口显示。窗口支持以下操作：

- 打开
- 关闭
- 最小化
- 拖拽移动
- 点击后置于最上层

窗口打开时会自动提高 z-index，保证当前操作的窗口位于其他窗口上方。

4. Field Notes 笔记应用

Field Notes 是项目中最完整的应用。用户可以在侧栏选择笔记，并对笔记执行以下操作：

- 打开已有笔记
- 修改标题
- 修改正文
- 新建笔记
- 保存笔记
- 删除笔记
- 随机切换笔记

笔记内容使用 localStorage 保存在浏览器中，因此刷新页面后仍然可以恢复。为了避免用户输入内容被当作 HTML 执行，编辑器使用纯文本输入框保存正文。

5. About.me 和 The Atlas

About.me 用于展示个人介绍、兴趣标签和外部链接。

The Atlas 是一个地图风格的交互窗口，用户点击不同地点后，可以查看对应的文字说明。它表达了“地点不仅是坐标，也可以承载记忆”的想法。

四、系统设置
------------

新增 System 应用后，用户可以：

- 修改桌面纯色背景
- 选择 Mint、Sunset、Night 等背景预设
- 使用图片 URL 设置壁纸
- 恢复默认背景
- 关闭当前界面并返回启动屏

背景设置保存在 localStorage 中。刷新页面时，系统会自动读取并恢复之前的背景。

五、标题字符交互
----------------

桌面上的大标题“Build a life you can visit.” 被拆分成多个独立字符。

点击某个字符后，该字符会向下掉落并淡出。当用户打开任意应用时，所有掉落的字符会恢复到原来的位置。这个交互让桌面标题也成为了可以探索的界面元素。

六、响应式适配
--------------

项目增加了移动端布局：

- 应用图标在小屏幕上自动换行
- 窗口宽度根据屏幕缩小
- Dock 保持在底部并适应窄屏
- 窗口内容可以在移动端滚动
- 页面没有横向溢出

七、测试与验证
--------------

开发过程中使用编辑器诊断检查 HTML、CSS 和 JavaScript，三个文件均未发现错误。

浏览器中验证了以下流程：

- 启动界面进入桌面
- 打开和关闭应用窗口
- 笔记打开、编辑、保存、新建和删除
- 笔记刷新后恢复
- 背景预设切换和持久化
- 关闭界面后返回启动屏
- 标题字符下落和恢复
- 移动端页面无横向溢出

八、当前项目结构
----------------

index.html    页面结构、桌面和应用窗口
style.css     视觉样式、动画和响应式布局
script.js     时钟、窗口、拖拽、笔记、文件和背景逻辑
readme.txt    英文项目说明
log.txt       开发日志

十、Mini Runner 小游戏
----------------------

新增 Mini Runner 应用，使用原生 Canvas 实现 LumenOS 风格的本地跑酷小游戏。玩家需要控制几何风格的小角色跳过珊瑚色障碍物，随着分数增加，游戏速度会逐渐提高。

小游戏支持以下操作：

- 点击 Start running 开始
- 使用 Space 或 Arrow Up 跳跃
- 移动端使用 jump 按钮
- 使用 pause 暂停，reset 重置
- 撞到障碍物后可以重新开始

障碍物增加了尖刺、方块、高柱和宽障碍四种形态，其中尖刺还可能成组出现。游戏速度根据存活时间逐步加快，并设置了合理上限以保持可玩性。

最高分使用 localStorage 保存在当前浏览器中，存储键为 lumenGameBest。游戏不依赖外部资源，也不嵌入第三方网页，关闭或最小化窗口时会暂停游戏循环。

十一、最后一个重大节点：Virtual Files 文件管理器
----------------------------------------------

在已有桌面和应用窗口的基础上，新增了 Virtual Files 文件管理器。文件管理器入口同时出现在桌面应用区和桌面右下角 Dock 中，但文件本身不会生成应用栏图标。

文件管理器支持以下操作：

- 新建文本文件
- 编辑并保存文本内容
- 从本地选择图片文件
- 从本地选择视频文件
- 打开图片并预览
- 打开视频并播放
- 删除文件
- 刷新文件列表

文件使用独立的 localStorage 存储键 lumenFiles 保存。每个文件包含名称、类型、MIME 类型、内容、大小和更新时间。文本内容直接保存，图片和视频在浏览器中读取为数据 URL 后保存，因此这些文件是当前浏览器中的虚拟文件，不会写入电脑的真实文件系统。

文件管理器还增加了空状态、保存失败、媒体读取失败和存储空间不足等提示，并针对移动端增加了单列布局。

总结
----

LumenOS 从一个空目录逐步发展成了一个具有桌面、窗口、应用、数据存储和视觉交互的个人 Web 操作系统。项目重点不只是展示内容，也尝试让访问者通过打开应用、编辑笔记和探索地图来了解创建者。
